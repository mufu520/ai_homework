# 影之刃零逆天者难度 AI 行为演示

人工智能概论第二次作业：MLP 参数学习的实现与可视化。

本作业由我与 Codex 联合完成。灵感来自《影之刃零》的适应性敌人设计；本作独立使用 MLP 实现课程模拟，不声称复现原作内部算法。

## 体验

[进入演示](./index.html)

首页介绍作品缘起；点击「进入行为演示」，再选择「观看演示」，即可观看约 56 秒的自动对局。也可选择格挡或闪避，与对手进行简单交手。概率条、网络图与损失曲线常驻展示。

进阶体验：点击顶部「记忆试炼」→「一键训练并演示」，比较模型如何利用操作顺序。首页、行为演示、记忆试炼、MLP 原理、实验记录共五页。

## 记忆试炼：同样的次数，不同的顺序

甲「格格闪格闪闪」、乙「闪格格闪格闪」，三次格挡且最后都是闪避。习惯统计会压缩掉顺序；这次让三个模型预测下一次防守：

| 模型 | 输入 | 参数 |
| --- | --- | --- |
| 习惯 MLP | 格挡比例 + 上次操作 | 33 |
| 顺序 MLP | 完整六次操作，按位置输入 | 65 |
| 记忆 RNN | 逐次读入，传递八维隐藏状态 | 89 |

用 64 种六次二元防守记录建立教学数据；脚本标签为重复倒数第三次操作。按类别分层切分 48 条训练、16 条测试，开场甲乙记录不参与训练。三者使用相同数据、Adam 学习率 0.01、300 次全批量更新。RNN 使用完整六步 BPTT 和全局范数上限 5 的梯度裁剪。更换种子会改变数据划分与初值。

可以播放/逐步读取记忆、点击改写历史、交换操作顺序，对比真实概率变化；展示八维隐藏状态、反向传播梯度以及训练/测试误差，支持导出完整实验记录。预测格挡时选破架斩，否则选追影斩；招式映射是固定规则，学习目标是防守预测。

顺序 MLP 是公平比较所需的基线，不预设 RNN 获胜。模型参数量和计算量不同，任务是简化的人工规律，不能据此声称 RNN 普遍优于 MLP。主演示仍使用原有命中率模型。对应课程第 12、15、16、19 节，本版没有加入强化学习或 Transformer。

## 学习过程

模型读取距离、最近防守习惯、上次防守和候选招式，预测各招命中概率。招式在当前防守选择前锁定；结算后仅用实际施展招式的结果作为标签，经反向传播和 Adam 更新参数。

- 战斗网络：6→8（tanh）→1（sigmoid），共 65 个参数。
- 学习目标：二元交叉熵；学习率 0.025；保留最近 12 条样本。
- 开局轮换探索，后续仍保留 22% 随机探索。
- 支持暂停、冻结学习、逐次拆解预测与参数更新、模型及记录导出。
- 课程 XOR 示例：2→2→1 网络；可逐步观察前向传播、梯度与训练。
- 对照实验：固定轮换、命中率统计、MLP，使用 12 个固定种子进行比较。

18 次演示用于说明学习过程，不代表充分训练。模型有探索和适应期，损失不保证单调下降。实验采用简化合成环境，不代表商业游戏或所有真人玩家。

## 文件

- `index.html`：内嵌 HTML、CSS、JavaScript 与图片的完整离线网页。MLP、RNN、反向传播、Adam 和界面源码均在此文件中。
- `README.md`：作品说明。
- `VALIDATION.md`：实际测试结果与完成边界；其中脚本路径指开发源码目录，测试脚本不包含在此精简上传目录内。

无需安装依赖、API Key 或后端。网页运行时不向远程服务发送对局、模型或个人数据；点击参考来源链接才会打开外部网站。

## GitHub Pages

更新已部署的这份作品：把此目录内的 `index.html`、`README.md`、`VALIDATION.md` 上传到当前作业仓库原有发布位置，覆盖三个同名文件。若原网页位于仓库根目录，就继续使用根目录，网站地址无需改变。`#memory` 可直接进入记忆试炼。

首次部署到另一个已有网站时，也可以新建 `mlp-demo` 子目录放入这三个文件，避免覆盖另一个网站的首页；此时访问网站地址后加 `/mlp-demo/`。

不要只上传 ZIP：GitHub Pages 发布网页文件，不会把仓库中的 ZIP 自动解压成网站。未开通 Pages 时，在仓库 Settings → Pages 中按官方文档配置发布源。
